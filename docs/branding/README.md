## 한국어

이 폴더의 PNG는 승인된 `ZUKU_Logo_Assets.zip`의 원본 바이트입니다.
밝은 배경에는 `zuku-logo-light.png`, 어두운 배경에는
`zuku-logo-dark.png`를 사용합니다. 이미지의 종횡비와 투명도를 유지하고,
로고를 다시 그리거나 색상·글자·슬로건을 이미지에 합성하지 않습니다.

공식 슬로건은 모든 언어에서 아래 문구를 그대로 사용합니다.

> ZUKU - 내가 불러 일으키는 새로운 창작.

README는 테마에 맞는 로고와 `ZUKU` 대체 텍스트를 제공합니다.
본문과 링크는 검색 및 접근성을 위해 텍스트로 유지합니다.
코드, 상류 저작권, 라이선스와 패키지 이름은 각 저장소의 기존 규칙을
따릅니다. 로고 교체는 소프트웨어나 브랜드 자산의 권리를 재허가하지 않습니다.

[한국어 개발 문서](https://docs.zuzunza.com/)에서 설치와 사용법을 확인하세요.
기능 구현, 검증, 릴리스와 운영 활성 상태는 각각의 소스와 증거를 따릅니다.

## English

These PNG files preserve the approved bytes from `ZUKU_Logo_Assets.zip`.
Use `zuku-logo-light.png` on light backgrounds and `zuku-logo-dark.png`
on dark backgrounds. Preserve their aspect ratio and transparency.
Do not redraw, recolor, or composite new lettering or slogans into the logo.

Use the exact official slogan above in every locale; do not translate it.
README images select the appropriate theme and include `ZUKU` alternative text.
Keep body content and links as text for search and accessibility.
Preserve each repository's source, upstream notices, licenses, and package names.
This brand update does not grant new software or brand asset rights.

See the [English developer documentation](https://docs.zuzunza.com/en/).
Implementation, testing, release, and production status require separate evidence.
